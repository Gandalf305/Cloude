# Anweisungen für Claude in diesem Repo

## Skills

- Skills liegen im Ordner `skills/`. Jeder Skill hat einen eigenen Unterordner mit einer `SKILL.md`.
- Vorlage für neue Skills: `skills/beispiel-skill/SKILL.md`.
- Ein Skill darf geladen und verwendet werden, wenn er zur aktuellen Aufgabe passt. Dafür muss das Frontmatter eine klare `description` haben.
- Vor dem Laden eines Skills kurz erwähnen, welcher Skill genutzt wird und warum.

## Änderungen

- Neue oder geänderte Dateien committen und auf `main` pushen, sofern der Push möglich ist.
- Commit-Nachrichten kurz und auf Deutsch halten.
