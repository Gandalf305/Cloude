# Beispiel-Skill

## Wann dieser Skill greift

Beschreibe hier konkret, in welchen Situationen Claude diesen Skill laden soll. Je genauer die Beschreibung im Frontmatter, desto zuverlässiger wird der Skill ausgewählt.

## Vorgehen

1. Schritt eins: Was zuerst geprüft oder gelesen werden soll.
2. Schritt zwei: Was daraufhin getan wird.
3. Schritt drei: Wie das Ergebnis aussehen soll.

## Regeln

- Formuliere klare, überprüfbare Anweisungen.
- Lege fest, was Claude nicht tun soll.
- Nenne ein Beispiel für ein gewünschtes Ergebnis, falls das hilft.
